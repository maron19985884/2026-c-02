# 変更要求書（テンプレート）

> **位置づけ**: フェーズ確定後に要件・設計・スコープの変更が発生した場合に **`/speckit.change` が本テンプレートをもとに変更要求書を生成します**。
> 人間はその出力をレビューし、承認を得てから変更を適用します。
> `docs/waterfall-preset-guide.md` の「変更管理プロセス」に対応します。
>
> **重要**: ウォーターフォールではフェーズ確定後の変更は必ず本書を通じて管理する。
> 変更要求書の承認なしに `spec.md`・`plan.md`・`tasks.md` を直接修正しない。
>
> **使い方**: 変更発生時に `/speckit.change [変更の概要]` を実行する → 出力を `docs/changes/CR-[連番]-[概要].md` として保存する → 人間が承認する。
> 本ファイル自体は AI の生成テンプレートです。直接編集する必要はありません。
