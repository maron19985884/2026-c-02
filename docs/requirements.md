# 要件定義書

> 出典: [user_requirements.md](../user_requirements.md)（ユーザー要件定義書：個人運営オンライン書店・購買フロー特化版）
> テンプレート: [requirements-template.md](requirements-template.md)
> 位置づけ: `/speckit.specify` を実行する **前に人間が記入する入力ドキュメント**。「何を作るか（What / Why）」のみを記載し、「どう作るか」は [技術選定書](tech-stack.md) に分離する。

## 1. 背景・目的

- **解決したい課題：**
  個人運営のオンライン書店において、訪問者が「本を探す → 選ぶ → 注文する」までを完結できる導線が存在しない。会員登録や決済といった重い仕組みを持ち込まずに、購買フローそのものを成立させる必要がある。

- **このシステム／機能で達成したいこと：**
  書籍の一覧・詳細閲覧からカート操作、注文情報の入力、注文確定・注文番号の受け取りまでを、ログイン不要で一連の流れとして完了できるようにする。

- **対象ユーザー：**
  書店サイトを訪れた購入希望者（未ログインの一般訪問者）。

## 2. スコープ

### やること（In Scope）

購買フローを構成する5画面。

| 画面 | 内容 |
|---|---|
| 画面1 商品一覧 | 販売中書籍のグリッド表示、詳細への遷移 |
| 画面2 商品詳細 | 書籍詳細情報の表示、カートへの追加 |
| 画面3 カート | カート内容の確認、数量変更、削除、合計金額表示、注文手続きへの遷移 |
| 画面4 注文フォーム | 氏名・住所・メールアドレスの入力とバリデーション、注文内容の同画面確認、注文確定 |
| 画面5 注文完了 | 注文完了メッセージ、注文番号の表示、商品一覧への復帰導線 |

### やらないこと（Out of Scope）

| 機能 | 除外理由 |
|---|---|
| ログイン・会員管理 | 本フローに不要 |
| 決済処理 | スコープ外 |
| 在庫管理 | スコープ外 |
| 管理画面 | スコープ外 |
| レビュー・評価 | スコープ外 |
| 検索・フィルター | スコープ外 |
| 送料などの表示ルール | スコープ外（合計金額は商品金額のみ） |

### 画面遷移

```
商品一覧 → 商品詳細 → （カートに追加）
                              ↓
                           カート → 注文フォーム → 注文完了
                              ↑
                         （一覧から直接も可）
```

## 4. 非機能要件

出典（`user_requirements.md`）に非機能要件の記載はない。以下は `/speckit.specify` 実行前に人間が確定させること。

- **性能（レスポンス・同時接続数など）：** 未確定 ※個人運営・小規模想定のため具体値の設定要否を含めて要判断
- **可用性・信頼性：** 未確定 ※稼働時間保証・バックアップ方針の要否を要判断
- **セキュリティ・権限：** 未確定。確定している事項は以下のみ
  - 認証・権限管理は行わない（ログイン・会員管理がスコープ外のため、全画面が未認証で閲覧・操作可能）
  - 注文フォームで氏名・住所・メールアドレスという個人情報を受け取るため、その保管・取り扱い方針は別途決定が必要
- **その他の制約（法規制・既存システム連携など）：** 未確定 ※決済がスコープ外のため、注文確定は受注記録までを指す

## 5. 受け入れ基準（Acceptance Criteria）

- [ ] 商品一覧画面で、販売中の書籍が書影・タイトル・著者・価格つきのグリッドで複数冊表示される（F-1, F-2）
- [ ] 一覧の書籍をクリックすると、その書籍の商品詳細画面に遷移する（F-3）
- [ ] 商品詳細画面に、書影・タイトル・著者・価格・説明文が表示される（F-4）
- [ ] 商品詳細画面で「カートに追加」を押すと当該書籍がカートに追加され、続けて商品一覧に戻って閲覧を再開できる（F-5, F-6）
- [ ] カート画面に、追加した書籍の書名・単価・数量・小計が表示される（F-7）
- [ ] カート画面で数量を増減すると、該当行の小計と全体の合計金額が即座に更新される（F-8）
- [ ] カート画面で書籍を削除すると、その行が消え合計金額が即座に更新される（F-9）
- [ ] カート画面に全商品の合計金額が表示される（送料等は含まない）（F-10）
- [ ] カート画面から注文手続きに進むと、注文フォーム画面に遷移する（F-11）
- [ ] 注文フォーム画面で氏名・住所・メールアドレスを入力できる（F-12）
- [ ] 氏名・住所・メールアドレスのいずれかが未入力、またはメールアドレスの形式が不正な状態で注文しようとすると、エラーメッセージが表示され注文は確定しない（F-13）
- [ ] 注文フォーム画面に、注文商品と合計金額が同時に表示される（F-14）
- [ ] 3項目を正しく入力して「注文する」を押すと、注文完了画面へ遷移する（F-15）
- [ ] 注文完了画面に、注文完了メッセージと注文番号が表示される（F-16, F-17）
- [ ] 注文完了画面から商品一覧へ戻るリンクで、商品一覧画面に遷移できる（F-18）

## 6. 用語定義

| 用語 | 意味 |
|---|---|
| カート | 購入予定の書籍と冊数を一時的に保持する入れ物。ログイン不要のため、利用者ごとの保持方法は設計時に決定する |
| 小計 | 書籍1点あたりの「単価 × 数量」 |
| 合計金額 | カート内の全書籍の小計の総和。送料・手数料・税の扱いはスコープ外 |
| 注文確定 | 注文フォームの内容で注文を受け付けること。決済はスコープ外のため、支払いの完了は含まない |
| 注文番号 | 確定した注文を一意に特定するための番号。注文完了画面で利用者に提示する |
