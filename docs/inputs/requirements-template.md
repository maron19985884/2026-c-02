# 要件定義書（テンプレート）

> **位置づけ**: `/speckit.specify` を実行する **前に人間が記入する入力ドキュメント**です。
> ここに書いた内容をもとに Spec Kit が `spec.md` を生成します。
> このファイルには「**何を作るか（What / Why）**」だけを書き、
> 「どう作るか（技術・アーキテクチャ）」は [技術選定書](../../tech-stack.md) に分けて記載してください。
>
> 使い方: 本ファイルをコピーして各項目を埋め、プロジェクトに配置してから `/speckit.specify` を実行します。
> フェーズ確定後の変更は [変更要求書](../change-request-template.md) を通じて管理します。
