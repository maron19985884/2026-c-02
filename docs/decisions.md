# 決定事項記録（Decision Record）

要件定義書に書かれていない仕様を決めたら、必ずここに 1 行追記し、`CLAUDE.md` の「決定事項」セクションにも反映する。
「決めていないことは必ずばらつく」ため、小さなことでも記録すること（プロンプト手法比較分析の教訓）。

## 運用ルール

- **Claude が仕様の空白を発見した場合**: 独自判断で実装せず、本ファイルに決定案を追記してユーザーに確認を求める
- **人間が仕様を決めた場合**: 同様に追記し、CLAUDE.md に反映する
- 決定を変更する場合は行を書き換えるのではなく、新しい行を追加して旧決定を打ち消す（経緯を残す）
