# frontend 規約

frontend 配下のファイルを扱う際に自動で読み込まれる規約。
ルートの `CLAUDE.md`（決定事項）が正（マスター）であり、本ファイルはそのサブセットの再掲。矛盾を見つけた場合はルートを優先し、本ファイルを修正すること。

## 画面 URL 設計（固定）

| URL | 画面 |
|---|---|
| `/` | 商品一覧 |
| `/books/[id]` | 商品詳細 |
| `/cart` | カート |
| `/checkout` | 注文フォーム |
| `/orders/[id]` | 注文完了 |

## 画面間のデータ受け渡し

- 注文完了画面へは URL パス（`/orders/[id]`）で ID を渡し、API で再取得する
- Context やメモリ上の状態のみでの受け渡しは禁止（リロードで消失するため）

## 実装規約

- ポートは **3000** 固定。API へのアクセスは `NEXT_PUBLIC_API_URL`（`http://localhost:4000`）経由
- TypeScript strict モード。`any` 型の使用禁止
