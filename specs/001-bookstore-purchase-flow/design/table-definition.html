ER概要

Book (1) ── (0..n) OrderItem (n..1) ── (1) Order

1. books（書籍）

管理画面がないため、DB初期化処理でのシードデータ投入のみで更新される（research.md参照）。

カラム名型制約説明
idINTEGERPRIMARY KEY AUTOINCREMENT書籍ID
titleTEXTNOT NULLタイトル
authorTEXTNOT NULL著者
priceINTEGERNOT NULL, > 0価格（円、税込）
descriptionTEXTNOT NULL説明文
image_urlTEXTNOT NULL書影画像URL

2. orders（注文）

POST /api/orders実行時にのみ1行作成される（更新・削除APIなし）。

カラム名型制約説明
idINTEGERPRIMARY KEY AUTOINCREMENT内部ID
order_numberTEXTNOT NULL, UNIQUE画面表示用注文番号（ORD-YYYYMMDD-NNNN）
customer_nameTEXTNOT NULL氏名
addressTEXTNOT NULL住所
emailTEXTNOT NULLメールアドレス
total_amountINTEGERNOT NULL, >= 0注文確定時点の合計金額
created_atTEXTNOT NULL注文日時（ISO8601）

3. order_items（注文明細）

注文確定時点の書籍タイトル・単価をスナップショットとして保持する。

カラム名型制約説明
idINTEGERPRIMARY KEY AUTOINCREMENT内部ID
order_idINTEGERNOT NULL, FOREIGN KEY → orders.id対象注文
book_idINTEGERNOT NULL, FOREIGN KEY → books.id対象書籍
titleTEXTNOT NULL注文確定時点の書籍タイトル（スナップショット）
priceINTEGERNOT NULL注文確定時点の単価（スナップショット）
quantityINTEGERNOT NULL, >= 1数量
subtotalINTEGERNOT NULLprice * quantity

備考

カート（Cart, CartItem）はDBに永続化しない。ログイン機構がないためフロントエンドの画面状態としてのみ保持し、注文確定時にのみorder_itemsとして永続化される（research.md「4. カートの永続化方式」参照）。
