# Quickstart: カート画面

本機能（カート画面 `/cart` の表示・数量増減・削除・合計金額・注文手続きへの遷移）を実装後、以下の手順で動作確認する。

## 前提

- Docker Desktop が起動していること
- `004-book-list-page` / `005-book-detail-page` が実装済みで、`docker compose up --build` により商品一覧・商品詳細画面から「カートに追加」ができること

## 起動

```bash
docker compose up --build
```

- frontend: http://localhost:3000

## 検証手順

### 1. カート内容の表示確認（User Story 1）

1. 商品一覧・商品詳細画面から2冊以上を「カートに追加」する。
2. ブラウザで http://localhost:3000/cart を開く。
3. **期待結果**: 追加した各書籍について書名・単価・数量・小計（単価×数量）が1行ずつ表示される（FR-001）。

### 2. カートが空の場合の表示確認（Edge Case）

1. ブラウザの開発者ツールで `localStorage` の `bookstore.cart` を削除するか、`[]` にする。
2. http://localhost:3000/cart を再読み込みする。
3. **期待結果**: 空状態メッセージが表示され、「注文手続きへ」ボタンは表示されない。商品一覧へ戻るリンクが表示される（FR-002, FR-010）。

### 3. 数量増減の確認（User Story 2）

1. カートに書籍が1件（数量1）ある状態で `/cart` を開く。
2. 数量の増加ボタンを押す。
3. **期待結果**: 数量が2になり、その行の小計とページ下部の合計金額が画面遷移なく即時に更新される（FR-004）。
4. 数量の減少ボタンを押して数量を1に戻す。
5. **期待結果**: 数量が1になり、小計・合計が再度更新される。
6. 数量1の状態でさらに減少ボタンを確認する。
7. **期待結果**: 減少ボタンが無効化されており、押しても数量は1のまま変わらない（FR-005）。

### 4. 削除の確認（User Story 3）

1. カートに書籍が2件ある状態で `/cart` を開く。
2. 1件の削除操作を行う。
3. **期待結果**: 当該行が一覧から消え、合計金額が削除した書籍の小計分だけ即時に減少する（FR-006, FR-007）。

### 5. 合計金額の確認（User Story 4）

1. カートに単価の異なる書籍を複数件入れ、`/cart` を開く。
2. **期待結果**: 表示される合計金額が、各行の小計の総和と一致する（FR-008）。

### 6. 注文手続きへの遷移確認（User Story 5）

1. カートに1件以上ある状態で「注文手続きへ」ボタンを押す。
2. **期待結果**: `/order` へ遷移する（注文フォーム画面自体は別機能で実装予定、FR-009）。

```bash

```
