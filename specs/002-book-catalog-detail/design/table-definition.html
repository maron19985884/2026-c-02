2.2 インデックス定義

インデックス名種別対象カラム目的
PRIMARYPRIMARY KEYid一意識別
idx_books_forsale_created INDEX（推奨・新規） is_for_sale, created_at DESC 一覧取得クエリ（WHERE is_for_sale=1 ORDER BY created_at DESC）の絞り込み・並び替えを効率化する
本機能のデータ規模（数十件程度、research.md想定）ではインデックスなしでも性能上の問題は生じないと見込まれるが、将来のカタログ規模拡大に備えた推奨インデックスとして記載する。必須の実装事項ではない。

2.3 制約

制約内容
CHECK（アプリケーション側）price は0以上の整数（DB制約ではなくアプリケーション側バリデーションとする。CHECK制約はMySQL 8.0.16+で利用可能だが本機能では必須としない）
一覧・詳細の対象常に is_for_sale = 1 の行のみを対象とする（アプリケーション側のWHERE句で担保。data-model.md参照）

3. 初期データ（シード）方針

mysql/init/01_books_seed.sqlにて、動作確認用に販売中・非販売（is_for_sale=0）を含む数件のサンプルレコードをINSERTする。CREATE TABLE IF NOT EXISTS + INSERTのみで構成し、DROP・TRUNCATE・DELETEは含めない（CLAUDE.md「破壊的DDLの直接生成禁止」に対応）。
