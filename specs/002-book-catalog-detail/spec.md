# Feature Specification: 商品一覧・商品詳細

**Feature Branch**: `002-book-catalog-detail`
**Created**: 2026-08-15
**Status**: Draft
**Input**: User description: "個人運営オンライン書店の商品一覧画面と商品詳細画面。販売中の書籍をグリッド形式で一覧表示し、書影・タイトル・著者・価格を確認できる。書籍をクリックすると商品詳細画面に遷移し、書影・タイトル・著者・価格に加え説明文を確認できる。詳細画面から「カートに追加」ボタンでカートに追加でき、追加後も一覧画面に戻って他の書籍を閲覧できる。ログイン・会員管理、検索・フィルター、レビュー・評価、在庫管理、決済処理、カートの中身確認・数量変更・削除は本機能の対象外（別機能として扱う）。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 販売中の書籍を一覧で確認する (Priority: P1)

書店サイトを訪れた利用者が、販売中の書籍をグリッド形式で一覧表示し、各書籍の書影・タイトル・著者・価格をひと目で把握できる。

**Why this priority**: 購買フロー全体の起点であり、これがなければ他のどの画面にも到達できない。単独でも「どんな本が売られているか分かる」という価値を提供できるため、最優先とする。

**Independent Test**: 一覧画面のみを実装した状態で、複数件の書籍データを表示し、各書籍の書影・タイトル・著者・価格がグリッド上に正しく表示されることを確認すれば検証が完結する。

**Acceptance Scenarios**:

1. **Given** 販売中の書籍が複数件登録されている、**When** 利用者が商品一覧画面を開く、**Then** 販売中の書籍がグリッド形式で表示される。
2. **Given** 商品一覧画面が表示されている、**When** 利用者が一覧中の書籍を確認する、**Then** 各書籍の書影・タイトル・著者・価格が表示されている。
3. **Given** 販売中の書籍が1件も存在しない、**When** 利用者が商品一覧画面を開く、**Then** 書籍が存在しない旨のメッセージが表示される。

---

### User Story 2 - 気になる書籍の詳しい情報を見る (Priority: P2)

一覧で見つけた書籍をクリックし、商品詳細画面で書影・タイトル・著者・価格に加え説明文を確認できる。

**Why this priority**: 購入検討に必要な追加情報（説明文）を提供する画面であり、一覧だけでは得られない価値を追加する。一覧(P1)がないと導線として機能しないため、一覧より後の優先度とする。

**Independent Test**: 一覧画面から任意の書籍への遷移を発生させ、詳細画面に書影・タイトル・著者・価格・説明文が表示されることを確認すれば検証が完結する。

**Acceptance Scenarios**:

1. **Given** 商品一覧画面が表示されている、**When** 利用者が任意の書籍をクリックする、**Then** その書籍の商品詳細画面へ遷移する。
2. **Given** 商品詳細画面が表示されている、**When** 利用者が画面を確認する、**Then** 書影・タイトル・著者・価格・説明文が表示されている。
3. **Given** 存在しない書籍IDが直接指定された、**When** 商品詳細画面を開こうとする、**Then** 書籍が見つからない旨のメッセージが表示される。

---

### User Story 3 - カートに追加して他の書籍も見続ける (Priority: P3)

商品詳細画面で購入意思が固まった書籍をカートに追加し、追加後もそのまま一覧画面に戻って他の書籍を見続けられる。

**Why this priority**: 購買フローを前に進める操作だが、カートの中身確認・数量変更・削除は別機能（カート画面）の責務であり、本機能では「追加できること」と「追加後も閲覧を継続できること」のみを対象とする。一覧・詳細の閲覧体験(P1・P2)が確立して初めて価値を持つため、優先度は最も低い。

**Independent Test**: 詳細画面で「カートに追加」ボタンを押し、追加が成功したことが画面上で分かることと、そのまま一覧画面に戻って他の書籍を閲覧できることを確認すれば検証が完結する。

**Acceptance Scenarios**:

1. **Given** 商品詳細画面が表示されている、**When** 利用者が「カートに追加」ボタンを押す、**Then** その書籍がカートに追加され、追加が成功したことが画面上で分かる。
2. **Given** 書籍をカートに追加した直後である、**When** 利用者が一覧に戻る操作を行う、**Then** 商品一覧画面に戻り、引き続き他の書籍を閲覧できる。

### Edge Cases

- 販売中の書籍が0件の場合、一覧画面はエラー表示ではなく「販売中の書籍がありません」といった空状態を示す。
- 書影画像が未設定の書籍がある場合、一覧・詳細のどちらでも代替表示（プレースホルダー）を行う。
- 存在しない、または販売終了済みの書籍IDに直接アクセスした場合、詳細画面はエラーではなく「見つかりません」の状態を示す。
- 説明文が長い書籍でも、詳細画面のレイアウトが崩れずに表示できる。
- 一覧・詳細のデータ取得に時間がかかる場合、読み込み中であることが利用者に分かる。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、販売中の書籍をグリッド形式で商品一覧画面に表示しなければならない。
- **FR-002**: システムは、商品一覧画面の各書籍について書影・タイトル・著者・価格を表示しなければならない。
- **FR-003**: 利用者は、商品一覧画面から任意の書籍をクリックして、その書籍の商品詳細画面に遷移できなければならない。
- **FR-004**: システムは、商品詳細画面に書影・タイトル・著者・価格・説明文を表示しなければならない。
- **FR-005**: 利用者は、商品詳細画面の「カートに追加」ボタンを押すことで、その書籍をカートに追加できなければならない。
- **FR-006**: 利用者は、カートに追加した後も商品一覧画面に戻り、他の書籍の閲覧を継続できなければならない。
- **FR-007**: システムは、ログインや会員登録なしに、一覧の閲覧・詳細の閲覧・カートへの追加を行えるようにしなければならない。
- **FR-008**: システムは、販売中の書籍が存在しない場合、一覧画面にその旨を示す空状態を表示しなければならない。
- **FR-009**: システムは、存在しない、または販売対象外の書籍IDが指定された場合、詳細画面に「見つかりません」状態を表示しなければならない。
- **FR-010**: システムは、検索・絞り込み、レビュー・評価、在庫数表示、ログイン・会員管理、決済処理を本機能の範囲に含めてはならない（他機能または対象外）。

### Key Entities *(include if feature involves data)*

- **書籍（Book）**: 販売対象となる書籍を表す。書影、タイトル、著者、価格、説明文、販売中かどうかの状態を持つ。商品一覧・商品詳細の両画面で参照される。
- **カート追加操作**: 利用者が特定の書籍に対して行う「カートに追加」という操作。本機能ではこの操作の起点のみを扱い、カートの中身の保持・表示・数量編集・削除は別機能（カート画面）の責務とする。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 商品一覧画面を開いた利用者は、追加の操作なしに任意の書籍のタイトル・著者・価格を確認できる。
- **SC-002**: 利用者は、商品一覧から気になる書籍の説明文まで、クリック1回で到達できる。
- **SC-003**: 「カートに追加」操作を行った利用者は、操作の成否を画面上で認識でき、かつ迷わず一覧画面に戻って閲覧を継続できる。
- **SC-004**: 販売中の書籍が0件の状態でアクセスした利用者は、エラーと誤解せず「今は書籍がない」と理解できる。

## Assumptions

- 書籍データ（タイトル・著者・価格・書影・説明文・販売可否）は本機能とは別の手段で用意されるものとし、本機能では書籍データの登録・編集は扱わない（管理画面は`user_requirements.md`により対象外）。
- カートの中身確認・数量変更・削除・合計金額表示は別機能（カート画面）の範囲であり、本機能は「カートに追加する」という操作の起点のみを提供する。
- 書籍カタログの規模は学習・デモ用途相当（数十件程度）を想定し、ページネーションなしで全件を一覧表示する（`requirements.md`の非機能要件「性能: 特定なし（学習・デモ用途）」に基づく合理的デフォルト）。
- 一覧の並び順について要件定義書に明記がないため、登録順（新しい書籍が先頭）をデフォルトとする（合理的デフォルト）。
- 書影画像が未設定の書籍にはプレースホルダー画像等の代替表示を行う（要件に明記がないための合理的デフォルト）。
- ログイン・会員管理は本プロジェクト全体のスコープ外であるため、閲覧・カート追加は匿名の利用者として行える。
