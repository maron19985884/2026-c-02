# Quickstart: カート画面

## 前提

- `docker compose up -d`でfrontend（3000番）・backend（4000番）・mysql（3306番）が起動していること（002-book-catalog-detailの環境をそのまま使用）
- 本機能はバックエンド・DBの変更を伴わないため、追加のセットアップ手順はない

## 動作確認シナリオ（spec.mdの受け入れ基準に対応）

| # | 手順 | 期待結果 | 対応 |
|---|---|---|---|
| 1 | 商品一覧画面または商品詳細画面からカートへの導線を選択する | 書籍を追加する操作を経由せずにカート画面(`/cart`)へ遷移する | US1 (FR-012) |
| 2 | カートに書籍を追加した状態でカート画面を開く | 各書籍の書名・単価・数量・小計と、全体の合計が表示される | US1 |
| 3 | カートが空の状態でカート画面を開く | 「カートに書籍がありません」等の空状態が表示される | US1 |
| 4 | ある書籍の数量を「+」で増やす | その行の小計と合計が、画面を再読み込みせず更新される | US2 |
| 5 | 数量が1の書籍で「−」を押す | 数量は1未満にならない（ボタンが無効化される、または変化しない） | US2 |
| 6 | ある書籍を「削除」する | その行が消え、合計が即時更新される | US3 |
| 7 | カートに1件だけの書籍を削除する | カートが空になり、空状態メッセージが表示される | US3 |
| 8 | カートに書籍がある状態で「注文手続きへ」を押す | 注文フォーム画面へ遷移する（画面自体は次feature） | US4 |
| 9 | カートが空の状態で「注文手続きへ」を確認する | ボタンが無効化されている、または押しても遷移しない | Edge Case (FR-011) |

## テスト実行

```bash
# フロントエンド（単体・コンポーネントテスト）
cd frontend && npm run test

# E2E（要: docker compose up -d が起動中であること）
cd e2e && npm run test
```
