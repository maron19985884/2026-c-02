## なぜ docs/ から分離したか

`docs/` は雛形を使う開発者が読むディレクトリで、`how-to-use.md` は「このリポジトリをそのままコピーして新規プロジェクトを始める」運用を前提としている。制作過程の記録を `docs/` に置いたままだと、無関係な新規案件にも本プロジェクト固有の改修履歴が複製されてしまうため、`_meta/` へ切り出した（`changelog.md` 対処10参照）。
